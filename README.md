# Flor de Feira

Lista de compras responsiva em português, feita com React, TypeScript e Vite.

## Começar

```sh
npm install
npm run dev
```

O Vite mostra no terminal o endereço local para abrir no navegador.

## Scripts

- `npm run dev`: inicia o servidor de desenvolvimento.
- `npm run build`: verifica os tipos e gera a versão de produção em `dist/`.
- `npm run preview`: serve localmente a versão gerada.
- `npm run lint`: executa o Oxlint.

## Recursos

- Adicionar itens com quantidade, categoria e preço.
- Filtrar por categoria, buscar, ordenar alfabeticamente e marcar compras concluídas.
- Acompanhar quantidade restante, progresso e total estimado.
- Remover itens e limpar os já comprados.
- Persistência automática no `localStorage` deste navegador.

Os dados permanecem no dispositivo atual; não há sincronização entre dispositivos.
